# Security Policy

## Reporting a Vulnerability

Maxit is an independent fork. Use private vulnerability reporting on the Maxit
repository when available; do not send fork-specific reports to upstream Kai.
No dedicated reporting address has been configured yet. Do not post exploit
details or secrets in a public issue.

### What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)
